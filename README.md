# abi's corner of the internet 💙

A personal, blue-and-lavender portfolio / digital scrapbook.

## Preview
Open `index.html` in your browser. An internet connection is needed for the Google Fonts; the site otherwise works offline.

## Add your photos
Put your own photos in `assets/photos/`, for example `campus.jpg`.
In `index.html`, replace the placeholder inside the matching `<div class="photo-placeholder">...</div>` with `<img src="assets/photos/campus.jpg" alt="A sunny afternoon on campus" style="width:100%;height:100%;object-fit:cover">`. You can do the same in the hero photo frame. Make sure you have permission to publish photos featuring other people.

## Add coursework
The three cards under “from the classroom” are intentionally placeholders, **not claims that you completed those projects**. Replace them with real course project names, summaries, technologies and links. If you share your project descriptions or GitHub repos, these can become full project cards.

## Update what you're doing now
Edit the `#now` section in `index.html` and update the date when your work changes.

## Publish with GitHub Pages
1. Create a public GitHub repository named `abirami07.github.io` (or use an existing Pages repository).
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` directory to the repository root.
3. In repository Settings > Pages, choose Deploy from a branch, main, /(root), then Save.
4. Visit https://abirami07.github.io once GitHub finishes deployment.

Your site is not published until you complete these steps.
